# VPN Gate TV
Push to GitHub -> Actions -> "Build APK" -> download artifact "VpnGateTV-apk".
The workflow fetches ics-openvpn (GPL v2), injects the VPN Gate TV screen (inject/) into it and builds.
Install the armeabi-v7a APK (or the universal one) on the receiver. Two launcher icons appear: the original OpenVPN UI and "VPN Gate TV".
